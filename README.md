# html_examples

A small collection of HTML examples for learning and reference.

## Contents

- `index-cats.html` — **CatPhotoApp**: a complete HTML page built following the
  freeCodeCamp HTML tutorial. It covers semantic page structure (`main`,
  `section`, `footer`), headings, paragraphs, links, images with `alt` text,
  unordered and ordered lists, the `figure`/`figcaption` elements, and a form
  with radio buttons, checkboxes, a text input and a submit button.

## How to view

Just open `index-cats.html` in any web browser — no server or build step needed.
